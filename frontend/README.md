# Team Task Assignment System

A simple task management application built with the MERN stack (MongoDB, Express, React, Node.js).

## Features
- **User Authentication:** Secure login and signup.
- **Task Management:** Create, view, update, and organize tasks.
- **Admin Dashboard:** Admins can manage users and assign tasks.

## How to Run the Project

You will need to run both the backend and frontend at the same time in two separate terminal windows.

### 1. Start the Backend
Open a terminal in the `backend` folder and run:
```bash
npm install
npm run dev
```

### 2. Start the Frontend
Open another terminal in the `frontend` folder and run:
```bash
npm install
npm run dev
```
